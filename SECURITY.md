# Security policy

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities.

Report them privately through [GitHub private vulnerability reporting](https://github.com/OpenWebconcept/plugin-openpub-base/security/advisories/new) or by email to [owc@yard.nl](mailto:owc@yard.nl).

Include the affected version, a description of the issue and the steps to reproduce it. We confirm receipt within 2 working days and keep you informed until the issue is fixed and released.
